# Contributing

Welcome. Code, documentation, accessibility feedback, Uyghur corrections and original cultural assets are useful contributions.

1. Check the project README and existing issues.
2. Describe one concrete problem or proposal. Include an example and the expected behavior.
3. Keep changes focused and run that project's tests.
4. Explain data provenance and licensing for new datasets or assets. Do not submit private information or unlicensed copied material.
5. Mark language and cultural claims as draft until an appropriate reviewer confirms them.

Use the project's GitHub Issues for public reports. Do not put credentials, private records or personal contact details into an issue.
