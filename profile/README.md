# UyghurCommunity · ئۇيغۇر ئاچقۇچىلار جەمئىيىتى

**Beautiful, practical open-source tools for building in Uyghur.**

ئۇيغۇر تىلى، مەدەنىيىتى ۋە رەقەملىك ئىجادىيىتى ئۈچۈن ئوچۇق مەنبەلىك قوراللار. كود، تىل تۈزىتىش، لايىھە ۋە قوللانما تۆھپىلىرىڭىزنى قارشى ئالىمىز.

[Developer hub / ئاچقۇچىلار مەركىزى](https://uyghurcommunity.github.io/) · [Doppa / دوپپا](https://uyghurcommunity.github.io/doppa/)

| Project | What it does |
| --- | --- |
| [Doppa](https://github.com/UyghurCommunity/doppa) | Interactive Uyghur cultural website and embroidery sculpture |
| [Doppa Kit](https://github.com/UyghurCommunity/doppa-kit) | Embeddable Canvas artwork, custom colors and SVG pattern export |
| [Uyghur UI](https://github.com/UyghurCommunity/uyghur-ui) | Uyghur writing, React adapters, 4 cultural themes, 6 installable components, 2 application blocks, 22 guides and 110 SVG icons (63 cultural) |
| [Doppa Studio](https://github.com/UyghurCommunity/doppa-studio) | Visual ornament editor with undo, symmetry and SVG/PNG/JSON exports |
| [Uyghur Text](https://github.com/UyghurCommunity/uyghur-text) | Unicode inspection, reversible cleanup and RTL fixture exports |
| [Uyghur Starters](https://github.com/UyghurCommunity/uyghur-starters) | Four standalone RTL website templates and the v0.2.0 CLI for 6 UI components |
| [Uyghur Keyboard](https://github.com/UyghurCommunity/uyghur-keyboard) | Virtual keyboard, Web Component and optional phonetic key mapping |
| [Lughet API](https://github.com/UyghurCommunity/lughet-api) | Dictionary search, suggestions, daily word and local/HTTP SDK |
| [Uyghur RTL Lab](https://github.com/UyghurCommunity/uyghur-rtl-lab) | Mixed-direction examples, Unicode inspection and frontend recipes |
| [Uyghur AI Eval](https://github.com/UyghurCommunity/uyghur-ai-eval) | Offline scoring tools and transparent draft evaluation tasks |

[Open the Uyghur UI Lab / ئىجاد تەجرىبىخانىسى](https://uyghurcommunity.github.io/uyghur-ui/lab.html) to try the writing field, explicit cleanup previews, **4 cultural themes**, **6 installable components**, and **2 application blocks** (dashboard and article editor). Core UI and the optional `@uyghurcommunity/ui-react` adapter are version **0.4.0**. Read the **22 guides** in [ئۇيغۇرچە](https://uyghurcommunity.github.io/uyghur-ui/guide/introduction.html) and [English](https://uyghurcommunity.github.io/uyghur-ui/guide/en/introduction.html).

[Explore the Uyghur UI Interactions gallery / جانلىق مىساللار](https://uyghurcommunity.github.io/uyghur-ui/interactions.html): **6 original website demos** with native controls, keyboard/touch support, reduced-motion handling, and 6 standalone HTML downloads including CSS and JavaScript. [Installation and UI documentation / قاچىلاش ۋە ئىشلىتىش قوللانمىسى](https://uyghurcommunity.github.io/uyghur-ui/guide/introduction.html) is available alongside the gallery.

6 ئەسلى جانلىق مىسالنى سىناڭ، كودىنى كۆچۈرۈڭ ياكى ھەر بىرىنى مۇستەقىل HTML ھۆججىتى قىلىپ چۈشۈرۈڭ. كۇنۇپكا تاختىسى ۋە چەكمە ئېكران بىلەن ئىشلىتىشكە بولىدۇ؛ ھەرىكەتنى ئازايتىش تەڭشىكىڭىزگە ئەمەل قىلىدۇ.

The dictionary entries and evaluation tasks are **original drafts awaiting community language review**. Synthetic evaluation examples demonstrate the tooling; they are not real model performance results.

## Get involved / تۆھپە قوشۇڭ

- Try a live demo and report a reproducible bug in that project's Issues.
- Suggest Uyghur text corrections with an explanation.
- Prepare a [dictionary contribution](https://uyghurcommunity.github.io/lughet-api/docs/contribute.html) with provenance for human review.
- Improve keyboard access, screen-reader output and real-device support.
- Propose original, clearly licensed cultural artwork or language data.
- Add small examples and help translate documentation.

Eight package artifacts across seven projects have versioned npm-compatible archives in their GitHub Releases, including the separate React adapter artifact in the UI repository. npm registry publication is deferred; each README describes the current installation path. All project websites use the externally linked ALKATIP Basma font for Uyghur text.
